# 配置检查记录

检查日期：2026 年 10 月 28 日。

使用实际下载的十个 Helm chart 渲染安装清单，按所选配置核对 Kubernetes 1.36 标准对象及可取得的 CRD 结构；检查配套 YAML 重复字段、嵌入配置、Python 语法、正文 Bash 代码块和私有文件权限。

存储后端与身份系统的两份 Compose 配置，通过 `docker compose config --quiet` 检查。凭据生成程序在工作目录实际执行，生成的文件权限核对为 0600。私有配置没有加入交付目录或 GitHub。

求和、持久化结果写入与读取程序已经在本地实际执行验证。Kubernetes Job、Volcano、GPU、SLURM、Calico BGP、NFS 和 IB 的目标集群运行结果，需要按正文逐项验收。

`validation.json` 保存本次配置检查的对象数量与范围。Calico、RKE2 HelmChartConfig 和 Multus 网络附件仍需要结合目标集群实际安装的 CRD 做服务端校验；CEL 准入表达式也需要在目标 API Server 通过服务端 dry-run 和实际允许、拒绝用例验证。

本文没有将配置渲染、结构校验写作 BBT 生产集群部署成功，也没有对生产集群执行安装、权限变更和故障演练。
